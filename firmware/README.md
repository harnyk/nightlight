# Прошивка (в работе)

Платформа: Seeed XIAO nRF52840, Arduino (Seeed nRF52 core) или PlatformIO.

План:
- эффекты на SK6812 RGBW (Adafruit NeoPixel, режим `NEO_GRBW`), яркость ограничена для ночника;
- TTP223: короткое касание — вкл/выкл / следующий эффект, долгое — яркость;
- таймер автоотключения (30–60 мин);
- управление по BLE (выбор эффекта, цвет, яркость, таймер);
- сон: лента отключена MOSFET, D0 в LOW, пробуждение по прерыванию от TTP223;
- зарядка 100 мА (P0.13 = LOW), контроль напряжения АКБ, отключение ленты ниже ~3.5 В.
